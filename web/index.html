API Integration Guide

Authenticate requests by passing your Session Key in the X-Session-Key or Authorization: Bearer header, or via ?key= query parameter.

Key in examples:
POST /api/upload
Permission: upload

Upload one or multiple files directly to Cloudflare R2 (optional folder prefix). Returns full download URLs, CDN public URLs, and comprehensive file metadata.

Example Request (cURL)
curl -X POST "http://localhost:8080/api/upload" -H "X-Session-Key: <session_key>" -F "file=@photo.png" -F "folder=uploads/2026/"
Example Response (JSON 200 OK)
{
  "message": "Files uploaded successfully",
  "count": 1,
  "url": "http://localhost:8080/api/file?key=uploads/2026/photo.png",
  "download_url": "http://localhost:8080/api/file?key=uploads/2026/photo.png",
  "public_url": "https://cdn.yourdomain.com/uploader/uploads/2026/photo.png",
  "file": {
    "name": "photo.png",
    "original_name": "photo.png",
    "key": "uploads/2026/photo.png",
    "full_key": "uploader/uploads/2026/photo.png",
    "bucket": "your-bucket",
    "size": 3853098,
    "content_type": "image/png",
    "etag": "e4d909c290d0fb1ca068ffaddf22cbd0",
    "md5_hash": "e4d909c290d0fb1ca068ffaddf22cbd0",
    "storage_class": "STANDARD",

  }
}
GET /api/file?key={file_key}
Permission: read

Stream or download an object directly from Cloudflare R2. Supports HTTP byte-range headers (Range: bytes=0-1024) for media streaming and seeking.

Example Request (cURL)
curl -O "http://localhost:8080/api/file?key=uploads/2026/photo.png" -H "X-Session-Key: <session_key>"
GET /api/file/info?key={file_key}
Permission: read

Retrieve object metadata, MD5 hash / ETag, exact byte size, MIME content type, storage class, and download links.

Example Request (cURL)
curl "http://localhost:8080/api/file/info?key=uploads/2026/photo.png" -H "X-Session-Key: <session_key>"
Example Response (JSON 200 OK)
{
  "name": "photo.png",
  "key": "uploads/2026/photo.png",
  "full_key": "uploader/uploads/2026/photo.png",
  "bucket": "your-bucket",
  "size": 3853098,
  "content_type": "image/png",
  "etag": "e4d909c290d0fb1ca068ffaddf22cbd0",
  "md5_hash": "e4d909c290d0fb1ca068ffaddf22cbd0",
  "last_modified": "2026-10-04T12:00:00Z",

  "metadata": {}
}
GET /api/files?path={path}
Permission: read

List subdirectories and files inside a folder in the R2 bucket (leave path empty for root directory).

Example Request (cURL)
curl "http://localhost:8080/api/files?path=uploads/2026" -H "X-Session-Key: <session_key>"
Example Response (JSON 200 OK)
{
  "current_path": "uploads/2026",
  "folders": [
    { "name": "backup", "path": "uploads/2026/backup" }
  ],
  "files": [
    {
      "key": "uploads/2026/photo.png",
      "name": "photo.png",
      "size": 3853098,
      "last_modified": "2026-10-04T12:00:00Z",
      "etag": "e4d909c290d0fb1ca068ffaddf22cbd0",
      "url": "http://localhost:8080/api/file?key=uploads/2026/photo.png",
      "public_url": "https://cdn.yourdomain.com/uploader/uploads/2026/photo.png"
    }
  ]
}
DELETE /api/file?key={file_key}
Permission: delete

Permanently remove an object from Cloudflare R2 storage.

Example Request (cURL)
curl -X DELETE "http://localhost:8080/api/file?key=uploads/2026/photo.png" -H "X-Session-Key: <session_key>"
Example Response (JSON 200 OK)
{
  "message": "Object 'uploads/2026/photo.png' deleted successfully"
}
POST /api/folder
Permission: upload

Create a virtual directory in Cloudflare R2 storage.

Example Request (cURL)
curl -X POST "http://localhost:8080/api/folder" -H "X-Session-Key: <session_key>" -H "Content-Type: application/json" -d "{\"path\": \"uploads/2026/new-folder\"}"
Example Response (JSON 201 Created)
{
  "message": "Folder created successfully",
  "path": "uploads/2026/new-folder"
}
DELETE /api/folder?path={folder_path}
Permission: delete

Permanently delete a folder and all its contents recursively from Cloudflare R2.

Example Request (cURL)
curl -X DELETE "http://localhost:8080/api/folder?path=uploads/2026/new-folder" -H "X-Session-Key: <session_key>"
Example Response (JSON 200 OK)
{
  "message": "Folder 'uploads/2026/new-folder' deleted successfully"
}
